problem: "Agricultural operators manage complex field conditions - soil moisture, temperature, humidity, pest risk - that affect yield outcomes. Raw sensor data is often inaccessible to operators without technical expertise, and existing telemetry displays are designed for offices rather than fields."
role: "I designed and built the embedded display interface - responsible for the hardware platform selection, sensor integration, data processing and the visual display logic that translated raw readings into contextually useful information for operators."
approach: "The project used a Raspberry Pi as the central processing unit with Python-based sensor polling and display logic. The interface was designed for glanceability - operators needed to read key metrics at a distance, in variable lighting. Early prototypes were tested against readability criteria before the display hierarchy was refined."
outcome: "A working embedded display prototype that pulled from multiple sensors and presented contextually structured data. Key learning: the interface design was as critical as the electronics - operators engaged far more with the visual display than with raw data logs."

Better access to field-level data could help smaller farms make better decisions without expensive proprietary systems. A practical, readable interface is as important as the sensor network behind it.
